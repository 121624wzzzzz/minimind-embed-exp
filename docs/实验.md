# Embedding/Head 变体预训练实验报告

> 更新日期：2026-06-29。本文描述当前仓库中的实验体系。已完成实验以
> `docs/eval_results/` 中的 CSV/JSON 为准；仍在运行的实验只记录配置，不提前给出结论。

## 1. 研究目标

本项目研究自回归语言模型中 input embedding 与 output projection（unembedding/lm head）
的绑定方式。所有对照实验保持 Transformer 主干不变，只修改 embedding/head 的有效参数化，
比较 `s1-s13` 在不同模型规模、语料、tokenizer、数据切分和随机种子下的验证 loss 与 PPL。

实验只覆盖从随机初始化开始的 pretrain，不包含 SFT、DPO、RL 或加载已有预训练权重后的微调。

项目包含三类模型配置：

- **MiniMind small**：hidden `768`，layers `8`。
- **MiniMind large**：hidden `1024`，layers `16`。
- **Qwen3-0.6B 架构配置**：hidden `1024`，layers `28`，attention heads `16`，KV heads `8`，
  head dim `128`，intermediate size `3072`，约 `595.8M` 参数。

“Qwen3-0.6B”实验指使用本仓库模型实现、Qwen3-0.6B 对齐配置和 Qwen3 tokenizer，
从随机初始化开始预训练。它在架构和 tokenizer 层面基本等价于从头训练 Qwen3-0.6B，

## 2. 模型变体

完整数学定义见 [`s1_s13_model_variants.tex`](s1_s13_model_variants.tex)，代码实现见
[`model/model_minimind.py`](../model/model_minimind.py)。低秩实验默认 rank 为 `32`。

| 变体 | 权重关系 | 核心修改 |
| --- | --- | --- |
| `s1` | tied | 标准 baseline，input embedding 与 lm head 共享权重 |
| `s2` | untied | input embedding 与 lm head 使用两个完整矩阵 |
| `s3` | tied | 输入侧全局平移 `embedding - beta` |
| `s4` | tied | 输入侧词表维加性低秩增量 |
| `s5` | tied | 输出侧词表维加性低秩增量 |
| `s6` | tied | 输入侧 hidden 维乘性低秩修正 |
| `s7` | tied | 输出侧 hidden 维乘性低秩修正 |
| `s8` | untied | untied + 输入侧全局平移 |
| `s9` | untied | untied + 输入侧词表维加性低秩增量 |
| `s10` | untied | untied + 输入侧 hidden 维乘性低秩修正 |
| `s11` | tied | 输出 projection 前的 hidden 全局平移 |
| `s12` | tied | `s3+s6`：输入侧平移与乘性低秩组合 |
| `s13` | tied | `s4+s6`：输入侧词表加性与 hidden 乘性低秩组合 |

所有新增分支都采用保持初始函数不变的初始化：`beta` 和低秩第二个投影为零，
低秩第一个投影使用 `N(0, 0.02)`。因此 tied 变体在 step 0 与 `s1` 具有相同的有效
input/output 映射，差异来自后续优化过程。

## 7. 梯度分析资产

历史 FineEdu GPT-2 tail 实验保存了 embedding/unembedding 梯度统计和可视化。该分析只对应
历史 GPT-2 6B tail 口径，不能直接当作当前 Qwen3 20B 实验的梯度结论。

主要文件：

- [`results/summaries/fineedu_s13_s5_grad_relation_summary.md`](../results/summaries/fineedu_s13_s5_grad_relation_summary.md)
- [`results/summaries/fineedu_s13_s5_grad_relation_summary.csv`](../results/summaries/fineedu_s13_s5_grad_relation_summary.csv)
- [`results/figures/`](../results/figures/)

已有观察包括：

- tied 权重的 input embedding 梯度与 output unembedding 梯度平均 cosine 接近 0，
  output 路径梯度范数约为 input 路径的 `1.85x-1.98x`。
- `s13` 的 hidden 乘性分支梯度大于词表加性分支，三个 seed 的 `mul/vocab` 均值比分别为
  `1.69x`、`1.19x`、`1.28x`。分支越强并不对应越好的 eval，seed123 的两个分支最均衡，
  同时取得该变体最大的相对收益。
- `s5` 输出侧 LoRA 梯度约为 shared 梯度的 `29%-35%`，但 eval 收益小且 seed2026 失效，
  说明新增模块梯度较大不等价于更好的泛化结果。

当前 FineEdu GPT-2 fixed-random 复验只保存标量梯度统计（`GRAD_SAVE_TENSORS=0`）。
完成后应先比较 random 与 historical-tail 的 loss/PPL 排序，再决定是否合并梯度层面的解释。

## 8. 综合判断

1. `s12` 是目前跨设置最稳定的结构：MiniMind small random、MiniMind large tail、
   FineEdu GPT-2 tail 和 FineEdu Qwen3 20B 中均取得最好或并列最好的结果。
2. `s3` 是参数成本最低的强 baseline，在多组实验中稳定优于 `s1`，但在 Qwen3 20B
   三 seed 平均上略弱于 `s12`。
3. `s2` 及 `s8-s10` 表明直接 full untied 在当前训练预算下明显不利；额外参数量不能自动
   转化为更低的验证 loss。
4. 输出侧单独修改 `s5/s7/s11` 的收益较小且稳定性不足，当前证据更支持输入侧修改。
5. Qwen3 配置在 MiniMind 数据上的负结果与 FineEdu20B 上的正结果共同说明：结构比较必须在
   足够匹配的 tokenizer、语料和 token 预算下进行。
6. 当前最重要的待完成证据是 FineEdu GPT-2 6B fixed-random 三 seed 复验，它将判断历史
   tail 排序是否能在无位置偏差的 eval split 上复现。

## 9. 结果与文件的权威顺序

为避免后续再次出现文档冲突，读取实验信息时按以下优先级：

1. 数据规模和来源：packed 目录中的 `preprocess_meta.json`。
2. train/eval 成员：`data_splits/*.json`。
3. 实际运行参数：对应 `scripts/experiments/` 或 `scripts/train/` 脚本及运行日志。
4. 原始 eval 数值：`docs/eval_results/**/eval_pretrain_loss*.csv/json`。
5. 三 seed 排序：`docs/eval_results/**/three_seed_summary.csv`。
6. 本文与 `docs/eval_results/README.md`：用于解释，不替代原始 CSV。

任何新实验只有在训练、完整 eval 和三 seed 汇总均完成后，才应从 `logs/` 迁入
`docs/eval_results/` 并更新本文结论。
